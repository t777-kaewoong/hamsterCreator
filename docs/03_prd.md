## 1. 목표와 성공 기준

### 1.1 제품 목표

> 햄스터S 말판과 라인트레이서 트랙을 화면에서 배치하고, 원하는 용지로 나눠 인쇄할 수 있는 정확한 축척의 PDF와 정답 코드를 함께 뽑아주는 교사용 웹 도구.

### 1.2 성공 기준

| # | 기준 | 측정 방법 |
|---|---|---|
| **S1** | 교과서 부록 p190(배리어 프리) 맵을 **5분 이내** 재현 | 실측 |
| **S2** | 인쇄물의 셀 피치가 **50mm ± 0.5mm** | 자로 실측 |
| **S3** | A4 4장 조립 후 격자가 **끊김 없이 연속** | 육안 + 로봇 주행 |
| **S4** | 생성된 파이썬 코드로 실물 햄스터가 **출발→도착 완주** | 실주행 |
| **S6** | 교과서 부록 p188(자율주행 도로) 재현 → **실물 라인트레이싱 주행 성공** | 실주행 |
| **S7** | 앱을 처음 보는 사람이 **안내 없이 10초 안에 첫 타일을 캔버스에 배치** | 관찰 (3명 이상) |

> **S7이 다른 기준만큼 중요합니다.** 기능이 아무리 많아도 첫 10초에 "이걸로 뭘 하는지"가 안 보이면 쓰이지 않습니다. §9 전체가 이 기준을 만족시키기 위한 명세입니다.

## 4. 시스템 아키텍처

### 4.1 배포

| 항목 | 값 |
|---|---|
| 저장소 | `t777-kaewoong/hamsterCreator` (**Public** — Pages 무료, 내장 아트는 저작권 프리) |
| 배포 URL | `https://t777-kaewoong.github.io/hamsterCreator/` |
| Vite `base` | `/hamsterCreator/` |
| 배포 방식 | GitHub Actions — `main` 푸시 시 빌드 후 Pages 배포 |
| 보안 컨텍스트 | HTTPS 기본 → `showSaveFilePicker` 사용 가능 |
| 오프라인 | Service Worker + `manifest.webmanifest` (PWA). 첫 방문 후 네트워크 없이 동작 |

**대피로 빌드:** `vite-plugin-singlefile`로 단일 HTML을 별도 산출해 릴리스에 첨부. 학교망 정책 변경이나 인터넷 단절 시 USB로 사용. `file://`에서는 localStorage가 막히므로 초안 자동 저장이 없고, 상단바에 상시 안내를 표시합니다.

> Apps Script 배포는 선택지로만 남깁니다. DB가 없어진 지금 서버가 할 일은 `doGet()` 하나뿐이고, GitHub Pages가 되는 환경에서는 샌드박스 iframe 제약(덮어쓰기 저장 불가)만 손해입니다.

### 4.2 맵 파일 형식 — `.hsmap.json`

파일명 규칙 `<제목>.hsmap.json`, UTF-8, 단일 JSON 객체.

**자기 완결성 원칙** — 파일 하나에 맵을 다시 그리는 데 필요한 모든 것이 들어갑니다.

| 항목 | 저장 방식 |
|---|---|
| 격자·엣지·자유곡선·마커 | JSON 값 |
| 내장 타일 참조 | `"dungeon/stone_a"` — 앱 번들에 있으므로 ID만 |
| 사용자 업로드 이미지 | base64 data URL을 파일에 직접 내장 |

**크기 추정:** 5×4 내장 타일만 3~5KB · 21×15 약 25KB · 사용자 이미지 10장 추가 시 400~700KB.

**호환성:** `schema` 필드로 버전 기록. 상위 버전은 경고 후 읽기 전용, 하위 버전은 마이그레이션 후 열기.

### 4.3 초안 자동 저장

편집 후 500ms 디바운스로 localStorage에 초안 저장(최근 5개). 다음 실행 시 초안이 있으면 복구 여부를 묻습니다. 명시적 저장 시 초안을 정리합니다.

- localStorage 상한(약 5MB) 때문에 **초안에는 사용자 이미지를 제외**하고 구조만 담습니다.
- 미저장 상태로 창을 닫으면 `beforeunload` 경고.
- 대피로 빌드(`file://`)에서는 초안 저장이 없습니다.

### 4.4 저장소 추상화

```ts
interface MapStore {
  readonly kind: 'file-overwrite' | 'file-download';
  readonly canOverwrite: boolean;
  open(): Promise<MapDoc>;
  save(doc: MapDoc): Promise<void>;
  saveAs(doc: MapDoc): Promise<void>;
}
```

| 구현 | 조건 | 저장 동작 |
|---|---|---|
| `FsaStore` | `showSaveFilePicker` 사용 가능 | 파일 핸들 유지 → 덮어쓰기 저장 |
| `DownloadStore` | 그 외 | Blob 다운로드 |

앱이 실행 시 감지해 저장 버튼 문구를 `저장` / `내려받기`로 바꿉니다.

## 5. 데이터 모델

```jsonc
{
  "schema": "hamsterS-map/1",
  "meta": { "title": "", "unit": "", "note": "", "createdAt": "", "updatedAt": "" },

  "board": { "cols": 5, "rows": 4, "pitch": 50, "lineWidth": 8 },

  "cells": [ { "art": "dungeon/stone_a", "rot": 0, "flip": false }, null, ... ],
  "edges": { "h": [[c,r], ...], "v": [[c,r], ...] },
  "stubs": [ { "node": [c,r], "dir": "W" } ],

  "strokes": [
    { "id": "s1", "kind": "spline",  "points": [[x,y], ...], "width": 8, "closed": false },
    { "id": "s2", "kind": "circle",  "cx": 200, "cy": 150, "r": 50, "width": 8 },
    { "id": "s3", "kind": "ellipse", "cx": 200, "cy": 150, "rx": 115, "ry": 75, "width": 8 },
    { "id": "s4", "kind": "line",    "points": [[0,100],[270,100]], "width": 8 }
  ],

  "props":  [ { "asset": "icon/fire", "x": 125, "y": 75, "w": 40, "h": 40, "rot": 0 } ],
  "labels": [ { "text": "출발", "x": 25, "y": 25, "rot": 0, "size": 8,
                "color": "#ffffff", "onLine": true } ],

  "markers": { "start": { "cell": [0,3], "heading": "E" },
               "goals": [ { "cell": [4,0], "name": "도착" } ] },

  "userAssets": { "u1": { "name": "우리학교.png", "w": 433, "h": 433,
                          "dataUrl": "data:image/png;base64,..." } },

  "print": { "sheet": "A4", "orientation": "landscape",
             "layout": "single", "seam": "butt", "overlap": 0,
             "cropMarks": true, "scaleRuler": true }
}
```

| # | 규칙 |
|---|---|
| D1 | 좌표 단위는 mm, 원점은 맵 좌상단 |
| D2 | 셀 `(c,r)`의 중심 = `(c·pitch + pitch/2, r·pitch + pitch/2)` = 격자 노드 |
| D3 | `cells` 길이 = `cols × rows`, row-major. 빈 셀은 `null` |
| D4 | 사용자 이미지는 `userAssets`에 data URL로 내장. 참조는 `asset:u1` |
| D5 | `edges`는 존재하는 선만 기록. 없으면 벽 |
| D6 | `pitch ≠ 50` 또는 `lineWidth ≠ 8`이면 경고 |
| D7 | 내장 타일은 ID만 기록 |
| D8 | `strokes`의 `width` 기본값 8mm |
| D9 | 격자와 자유곡선은 한 문서에 공존. 어느 한쪽이 비어도 유효 |

**렌더 순서 (고정):** 흰 배경 → `cells`의 `floor`·`block` 아트 → `strokes` → `edges` → `cells`의 `object` 아트 → `props` → `labels` → `markers`. 바닥 무늬와 블록 위에는 경로가 보여야 하지만, 상자·금화 같은 낱개 물건은 바닥 위에 놓인 장애물이므로 경로보다 위에 그립니다.

## 9. UI · 디자인 명세

> **이 절은 구현자가 추측 없이 만들 수 있도록 수치를 확정합니다.** 값이 명시된 곳은 그대로 쓰고, 명시되지 않은 것만 판단하십시오.

### 9.1 UI 원칙

| # | 원칙 | 구체적 의미 |
|---|---|---|
| **U1** | **10초 규칙** | 시작 화면에서 클릭할 대상이 즉시 보이고, 편집기 진입 후 첫 배치까지 설명이 필요 없어야 한다. 튜토리얼 모달·가입·설정 화면을 첫 진입에 두지 않는다 |
| **U2** | **보여주고 말하지 않는다** | 선택지는 글자가 아니라 **그림**으로 제시한다. 프리셋은 실제 렌더 썸네일, 타일은 실제 이미지, 용지 분할은 도식으로 보여준다 |
| **U3** | **중립 크롬, 화려한 내용** | 내장 아트가 매우 컬러풀하므로 UI 크롬은 회색 계열로 중립을 유지한다. 강조색은 한 가지만 쓴다 |
| **U4** | **종이가 주인공** | 캔버스의 흰 아트보드가 화면에서 가장 밝고 넓은 요소여야 한다. 주변은 한 단계 어두운 회색으로 눌러 종이를 띄운다 |
| **U5** | **점진적 공개** | 기본 화면은 단순하게, 고급 옵션은 선택 시 인스펙터에 나타나거나 `고급` 토글 뒤에 둔다. 기능을 줄이지 말고 **숨긴다** |
| **U6** | **즉각적 시각 피드백** | 호버·선택·배치 예정 위치를 항상 미리 보여준다. 클릭 후에야 결과를 알게 하지 않는다 |
| **U7** | **파괴적 동작은 되돌릴 수 있게** | 확인 모달 대신 실행취소로 처리한다. 모달은 흐름을 끊는다 |

### 9.2 레이아웃 골격

편집기는 CSS Grid 1개로 구성합니다. 세로는 `56px 1fr`, 가로는 `64px 280px 1fr auto`.

| 영역 | 크기 | 배경 | 비고 |
|---|---|---|---|
| 상단바 | 높이 **56px**, 전체 폭 | `--c-surface` + 하단 1px `--c-border` | 고정 |
| 도구 레일 | 폭 **64px** | `--c-surface` + 우측 1px `--c-border` | 세로 스크롤 없음 |
| 팔레트 패널 | 폭 **280px** | `--c-surface` + 우측 1px `--c-border` | 세로 스크롤 |
| 캔버스 뷰포트 | 나머지 | `--c-canvas-bg` | 스크롤 없음(팬/줌으로 이동) |
| 인스펙터 | 폭 **300px**, 접으면 **0** | `--c-surface` + 좌측 1px `--c-border` | 세로 스크롤 |

- 인스펙터 접기 버튼은 캔버스 우상단에 부유시킵니다(§9.13).
- 뷰포트 폭이 1180px 미만이면 인스펙터를 자동으로 접습니다.
- 최소 지원 폭 1024px. 그 미만에서는 상단에 안내 배너를 띄우되 기능은 막지 않습니다.

- `prefers-reduced-motion: reduce`일 때 모든 트랜지션 지속시간을 `0.01ms`로 낮춥니다.

### 9.12 편집기 — 캔버스 뷰포트 ★핵심

**좌표 변환**

- 상태값 `pxPerMm`을 유지합니다. 초기값은 아트보드가 뷰포트에 여백 48px을 남기고 들어가는 값(맞춤).
- 확대 범위 0.5~8 `pxPerMm`. 휠 확대는 커서 위치 기준, 배율 1.15배씩. `Ctrl` 없이 휠은 세로 팬, `Shift`+휠은 가로 팬, `Ctrl`+휠은 확대/축소.
- `Space` 누른 채 드래그 또는 마우스 가운데 버튼 드래그로 팬. 커서를 `grab`/`grabbing`으로 바꿉니다.

**렌더링**

- 캔버스 요소는 `devicePixelRatio`를 곱한 실제 크기로 만들고 컨텍스트를 `scale(dpr, dpr)`합니다. 저해상도 렌더 금지.
- 레이어를 오프스크린 캔버스로 분리하고 변경된 레이어만 다시 그립니다: ① 종이+안내선 ② 아트 타일 ③ 곡선+격자선 ④ 프롭+라벨+마커 ⑤ 오버레이(호버·선택·고스트).
- 아트 타일은 원본 비트맵을 `ImageBitmap`으로 미리 디코드해 캐시합니다.

**정적 요소**

| 요소 | 규격 |
|---|---|
| 아트보드 | `--c-paper` 배경, 그림자 `--e2`, 테두리 없음 |
| 셀 경계 안내선 | 1px `--c-guide`, 비인쇄. `pxPerMm < 1.2`이면 숨김 |
| 격자 노드 점 | 지름 3px `--c-node`, 셀 중심. 로봇이 서는 지점을 알려주는 핵심 단서 |
| 격자선·곡선 | `#000000`, 실제 mm 굵기 그대로 |
| 눈금자 | 캔버스 상단·좌측에 두께 24px. 배경 `--c-surface-2`, 눈금 10mm마다 4px, 50mm마다 8px + `micro` 숫자. 원점은 아트보드 좌상단 |

> **눈금자는 v1 필수입니다.** "이 도구는 실제 크기를 다룬다"는 사실을 말없이 전달하는 가장 효율적인 장치입니다.

| 곡선 편집 | 정점 원 7px(흰 채움, 2px `--c-primary`), 곡선 핸들은 3px 원 + 1px 연결선 |
| 시트 경계 (미리보기 켬) | 2px 파선 `--c-seam`, 각 시트 좌상단에 `micro` 번호 칩(`--c-primary` 배경, 흰 글자) |
| 검증 경고 위치 | `--c-warn-zone` 채움 + 2px 실선 `--c-warn` 윤곽 |
| 출발 마커 배치 고스트 | 대상 노드에 2px 파선 `--c-primary` 원 + `출발` 칩 |
| 도착 마커 배치 고스트 | 대상 노드에 2px 파선 `--c-primary` 원 + `도착` 칩 |

> **정정 (2026-09-06):** 이 표는 화면에만 보이고 인쇄되지 않는 오버레이를 규정합니다.
> 초판에는 출발·도착 마커가 `지름 28px 원(--c-ok / --c-primary 배경)`으로 이 표에 들어
> 있었으나, FR-4.3·FR-4.4가 요구하는 출발·도착 마커는 **말판에 실제로 인쇄되는 그림**
> 입니다(교사가 출력한 종이 위에서 로봇을 출발시켜야 하므로). 화면 px 단위·색 구분으로는
> 인쇄물에서 크기가 달라지고 흑백 출력에서 구분이 사라집니다.
>
> 그래서 마커 **본체**는 §5 렌더 순서의 `markers` 단계에서 **mm 실치수·흑백 모양 구분**
> 으로 그리고(§9.17 "오류·경고를 색으로만 구분하지 않는다"와 같은 원칙), 이 오버레이
> 표에는 **배치 전 미리보기(고스트)만** 남깁니다.
>
> 인쇄되는 마커 규격: 출발 = 바깥지름 34mm·선폭 3mm 빈 원 + 안쪽에 진행 방향 삼각형,
> 도착 = 34mm/22mm 겹원(과녁 모양). 둘 다 아래에 6mm 글자로 이름. 색은 검정 단색.
> (칸 50mm 안에 여백을 두고 들어가는 크기로 역산한 값)

**부유 컨트롤**

- **줌 클러스터** — 캔버스 우하단, 여백 16px. 높이 36px, 배경 `--c-surface`, 반경 `--r-pill`, 그림자 `--e2`. 내용은 `ZoomOut` · 배율 표시(`label`, 클릭 시 100%로) · `ZoomIn` · 구분선 · `Maximize2`(맞춤).
- **미니맵** — 캔버스 우상단, 여백 16px, 폭 160px. 맵 종횡비에 맞춘 높이. 배경 `--c-surface` 80% 불투명, 반경 `--r-md`, 그림자 `--e1`. 현재 뷰포트를 2px `--c-primary` 사각으로 표시. `pxPerMm`이 맞춤 배율 이하이면 자동으로 숨깁니다.
- **인스펙터 접기 버튼** — 캔버스 우상단, 미니맵 위 8px. 32×32 아이콘 버튼.

### 9.13 편집기 — 인스펙터

폭 300px, 좌우 여백 16px. 섹션 간 간격 24px, 섹션 제목은 `h2` + 하단 8px 여백.

**섹션 구성 (위에서 아래로)**

1. **선택 항목** — 아무것도 선택되지 않았으면 이 섹션을 통째로 숨깁니다. 선택 시 종류별로 다른 필드를 보여줍니다.
   - 타일: 회전(세그먼트 0/90/180/270), 좌우 반전(토글), 삭제(ghost danger)
   - 프롭: X·Y·너비·높이(mm 입력 4개, 2열 배치), 회전, 삭제
   - 라벨: 텍스트 입력, 크기(mm), 색(스와치 6종 + 사용자 지정), 선 위 흰 글씨 토글, 회전
   - 곡선: 종류 표시, 선폭(mm), 정점 수, 총 길이(mm), 닫힌 경로 토글, 삭제
2. **맵 설정** — 격자 열·행(숫자 입력 2개), 피치(mm), 선폭(mm). 피치·선폭이 기본값에서 벗어나면 입력 아래에 `--c-warn` 색 `caption` 한 줄 경고.
3. **용지** — 용지 선택(드롭다운), 방향(세그먼트 가로/세로), 분할 방식(세그먼트 단일장/나눠 인쇄). 하단에 결과 요약 한 줄(`A4 가로 4장 · 이음매 4곳`)과 `출력 계획기 열기` ghost 버튼.
4. **검증** — 경고가 0건이면 제목 옆에 `CircleCheck` + `문제 없음`만 표시하고 접습니다. 1건 이상이면 목록을 펼칩니다. 각 항목은 높이 최소 44px, 좌측 색 막대 3px(오류 `--c-danger` / 경고 `--c-warn`), 아이콘 16px, 본문 `caption` 2줄까지. 클릭하면 해당 위치로 캔버스를 이동하고 0.6초간 깜빡입니다.

**접기 동작:** 접으면 폭 0이 되고 캔버스가 즉시 넓어집니다(`--t-base`). 접힌 상태에서도 경고가 새로 생기면 접기 버튼에 `--c-warn` 색 6px 점 배지를 띄웁니다.

### 9.14 출력 계획기 모달 ★핵심

**용지 선택지를 글자 표가 아니라 도식으로 보여주는 것이 이 모달의 존재 이유입니다**(U2).

**크기·구조**

모달 폭 940px, 높이 640px(뷰포트가 작으면 `min(940px, 92vw)` / `min(640px, 88vh)`). 본문은 좌우 2단으로 나눕니다: 좌측 옵션 목록 340px, 우측 미리보기 나머지, 사이 1px `--c-border`.

**상단 입력 영역** (본문 위, 높이 72px, 하단 1px `--c-border`)

- 세그먼트 컨트롤: `격자 크기로` / `실물 크기로`
- 선택에 따라 입력 2개 노출: 열×행 또는 가로×세로(mm)
- 우측 끝에 정렬 기준 드롭다운: `장수 최소` / `이음매 최소` / `낭비 최소`

**좌측 옵션 목록**

각 옵션은 카드 하나이며 높이 96px, 간격 8px, 반경 `--r-lg`, 테두리 1px `--c-border`.

카드 내부는 좌측 **도식 84×84px**, 우측 정보로 나눕니다.

- **도식은 SVG로 그립니다.** 맵 전체 비율의 사각형 안에, 시트 분할선을 1px `--c-text-3`으로 긋고 각 시트 칸을 `--c-surface-2`로 채웁니다. 배경에는 맵 썸네일을 불투명도 0.35로 깔아 어떤 맵인지 보이게 합니다. **이 도식만으로 "A4 4장을 2×2로"가 즉시 읽혀야 합니다.**
- 우측: 1행에 용지명 `label` + 장수 배지(`micro`, `--c-primary-soft` 배경). 2행에 `이음매 4곳 · 낭비 0칸`(`caption`, `--c-text-2`). 3행은 낭비 0이면 `딱 맞음` 칩(`--c-ok` 글자, `#ECFDF5` 배경), 이음매 0이면 `이음매 없음` 칩.
- 선택된 카드: 테두리 2px `--c-primary`, 배경 `--c-primary-soft`.
- **추천 옵션**(정렬 기준 1위)은 목록 맨 위에 두고 우상단에 `추천` 배지를 붙이며 모달 열릴 때 미리 선택합니다.

**우측 미리보기**

선택한 옵션대로 맵 전체를 렌더하고 그 위에 시트 경계를 2px 파선 `--c-seam`으로, 각 시트 좌상단에 번호 칩을 그립니다. 하단에 `이음매 방식` 세그먼트(맞대기 / 겹치기)와 겹치기 선택 시 mm 입력을 둡니다.

**푸터**

좌측에 예상 결과 한 줄(`A4 가로 4장 + 조립 안내도 1장`), 우측에 `취소`(ghost)와 **`PDF 만들기`(primary)**.

**생성 중 상태:** primary 버튼을 비활성화하고 라벨을 `만드는 중…`으로 바꾸며 버튼 안에 좌→우로 채워지는 2px 진행 막대를 그립니다. 완료 시 토스트로 알립니다.

### 9.15 첫 사용 안내와 빈 상태

**모달 튜토리얼을 만들지 않습니다.** 대신 다음 두 가지만 둡니다.

1. **코치 마크 1개** — 편집기 최초 진입 시에만, 팔레트 첫 타일 우측에 말풍선(배경 `#1A1D21`, 흰 글자 `caption`, 반경 `--r-md`, 그림자 `--e2`, 좌측 화살표 6px). 문구는 `타일을 고르고 칸을 클릭하세요` 한 줄. **첫 배치가 일어나면 즉시 사라지고 다시 뜨지 않습니다**(localStorage 플래그).
2. **캔버스 빈 상태** — 아트 타일이 하나도 없을 때, 아트보드 중앙에 `--c-text-3` 색 `body` 한 줄 `왼쪽에서 타일을 골라 칠해 보세요`. 첫 배치 시 사라집니다. 이 문구는 인쇄·미리보기·PDF에 절대 포함되지 않습니다.

**그 밖의 빈 상태**

| 상황 | 표시 |
|---|---|
| 검색 결과 없음 | 팔레트 중앙에 `caption` 한 줄 + `검색 지우기` ghost 버튼 |
| 내 이미지 없음 | 드롭존 축소판(높이 72px) + `이미지 추가` 버튼 |
| 최근 파일 없음 | 시작 화면에서 해당 영역 자체를 숨김 |

### 9.16 피드백과 상태 표시

| 사건 | 피드백 |
|---|---|
| 타일 배치 | 즉시 렌더. 토스트 없음 |
| 실행취소 | 토스트 없음. 상단바 버튼 상태만 갱신 |
| 저장 성공 | 상태 칩이 `저장됨`으로. 토스트 없음 |
| 저장 실패 | 토스트(danger 톤) + `다시 시도` 버튼 |
| PDF 생성 시작 | 버튼 내 진행 표시(§9.14) |
| PDF 생성 완료 | 토스트 `PDF를 내려받았습니다` |
| 파일 열기 실패 | 모달이 아닌 토스트 + 사유 한 줄 |
| 초안 복구 가능 | 시작 화면 최상단에 배너(높이 56px, `--c-warn-soft` 배경) + `복구` / `버리기` 버튼 |
| 도달 불가 발생 | 인스펙터 검증 섹션에 오류 추가 + 해당 위치 캔버스 강조. 배치를 막지 않음(FR-9.6) |

**작업 표시 규칙:** 1초 미만이면 아무것도 표시하지 않습니다. 1초 이상이면 해당 버튼 안에서 진행을 표시하고, 전체 화면 로딩 오버레이는 쓰지 않습니다.
