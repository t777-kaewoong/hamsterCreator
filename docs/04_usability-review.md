# 04. 실사용 전 최종 검토 — 사용자 후기 반영 (2026-09-28)

> 순서: 문제 분석 → 개선 방향 → 명세 → 검토. 구현은 이 문서의 §3 명세를 그대로 따른다.

## 1. 문제 분석

### 1.1 받은 후기 (원문 요지)

1. "간편한데 불편하다. A4를 미리 정해야 하는 것도 좋은데 안 좋다. 맵을 만드는 과정에서 **종이 추가** 같은 편의 기능을 넣으면 안 되나?"
2. "사이드바 글씨가 **정렬이 안 되어 있고 뒤죽박죽**이다."

### 1.3 판단

- 후기 1의 본질은 "용지를 **먼저** 결정하게 하는 흐름"이다. 용지 선택 자체는 유지하되, **만드는 도중에 종이를 이어 붙이거나 떼는 조작**을 캔버스에 직접 두면 시작 화면의 선택이 되돌릴 수 없는 결정이 아니게 된다.
- 종이를 붙이려면 지금 종이가 어디서 끝나는지 보여야 한다(F2). 이음매 표시는 출력 계획기와 **같은 계산**(`findPrintPlan`)을 써야 화면과 인쇄물이 어긋나지 않는다.
- "단일장/나눠 인쇄"는 사용자가 고를 값이 아니라 맵 크기와 용지로 **결정되는 값**이다(F5). 자동으로 정하고 선택지를 없앤다.
- 후기 2는 정렬 규칙이 하나로 통일되지 않은 문제다. 모든 행을 **같은 2열 격자(라벨 열 고정 폭 + 컨트롤 열)**로 맞춘다.

## 3. 명세

### 3.1 크기 변경 규칙 (U3) — `lib/model/resize.ts`

`reframeMapDoc(doc, shiftCols, shiftRows, nextCols, nextRows)` 하나로 통일한다. 옛 칸 (c, r)은 새 칸 (c + shiftCols, r + shiftRows)가 된다.

- cells: 새 좌표로 다시 배치(row-major 공식 재계산). 범위 밖은 버림.
- edges: 옛 맵이 **전체 격자**(h = (cols−1)×rows, v = cols×(rows−1))였으면 새 크기로 전체 격자를 다시 만든다. 아니면 평행 이동 후 범위 밖 제거.
- stubs: 옛 맵이 "경계 전체" 세트였으면 새 크기로 다시 만든다. 아니면 평행 이동 후 기존 규칙(가장자리였다가 안쪽이 된 것 제거, 원래 안쪽이던 것 유지).
- markers: 평행 이동, 범위 밖 제거.
- props·labels·strokes: mm 좌표를 (shiftCols×pitch, shiftRows×pitch)만큼 이동. 새 종이 영역과 전혀 겹치지 않게 된 것만 제거.
- print.layout: 맵이 현재 용지 1장에 들어가면 `'single'`, 아니면 `'tiled'`로 자동 설정.
- 기존 `resizeMapDoc(doc, cols, rows)`는 `reframeMapDoc(doc, 0, 0, cols, rows)`.

### 3.2 종이 붙이기·떼기 (U1) — `CanvasViewport`

- 한 장 크기 = 현재 용지·방향이 담는 칸 수. A4 가로 = 가로 5칸 × 세로 4칸, A4 세로 = 4 × 5. (`floor(용지mm / pitch)`)
- 붙이기: 그 방향으로 한 장 크기만큼 칸 추가. 오른쪽 +5열, 아래 +4행, 왼쪽·위도 같다.
- 떼기: 그 방향 끝의 **마지막 종이 한 장**만큼 제거. 제거량 = `칸수 % 한장칸수`(0이면 한장칸수). 남는 칸이 1 미만이 되면 버튼 비활성.
- 조작 한 번 = 실행취소 한 단계. 조작 후 화면 맞춤(fit) 자동 실행. 떼기로 내용이 사라졌으면 토스트 "종이를 뗐습니다 · Ctrl+Z로 되돌리기".
- 모양: 변 가운데, 종이 바깥 여백(맞춤 여백 48px) 안에 뜨는 알약.
  - 좌·우 변: 세로 알약, 폭 40px. 위에서부터 [+ 버튼 32×32] [글자 "종이" 11px] [− 버튼 32×32]. 종이 가장자리에서 4px 떨어짐.
  - 위·아래 변: 가로 알약, 높이 40px. 왼쪽부터 [−] ["종이"] [+].
  - 배경 `--c-surface`, 테두리 1px `--c-border-strong`, 그림자 `--e1`, 반경 `--r-pill`. 버튼 아이콘 16px, 호버 배경 `--c-primary-soft` + 글자 `--c-primary`.
  - 툴팁: "오른쪽에 종이 붙이기 (+5칸)", "오른쪽 종이 떼기 (−5칸)" 식.
  - 팬·줌을 따라 움직인다(React 리렌더 없이 rAF에서 style만 갱신). 알약이 캔버스 밖으로 나가면 숨긴다.

### 3.3 종이 경계 표시 (U2) — `drawOverlay.ts`

- `findPrintPlan(doc)` 결과(출력 계획기와 같은 계산)의 열·행 절단 위치에 파선. 색 `--c-seam`(#4F46E5), 폭 2px, 대시 [8, 6]. 인쇄되지 않음.
- 종이가 2장 이상일 때만 그린다. 각 종이 좌상단 안쪽 6px에 번호 배지: 높이 18px 알약(글자 폭 + 좌우 6px), 배경 `--c-seam`, 흰 글자 11px 600.
- 번호는 PDF 머리글·출력 계획기와 같은 **"행-열" 코드**(1-1, 1-2, 2-1 …). 화면 번호와 인쇄물 번호가 같아야 조립할 때 헷갈리지 않는다.
- 계산은 문서가 바뀔 때만(WeakMap 캐시) — 마우스 이동마다 다시 계산하지 않는다.

### 3.4 인쇄·미리보기 (U4, U5) — `TopBar.tsx`

- 인쇄: 맵이 용지 1장에 들어가면 바로 PDF 내려받기, 아니면 출력 계획기 열기. 저장된 `print.layout` 값은 보지 않는다.
- 출력 계획기는 열릴 때 **편집 중인 용지**(캔버스에 경계로 보이던 계획)를 골라 두고 그 카드로 스크롤한다. 카드에 "편집 중인 용지" 칩(`--c-primary-soft` 배경, `--c-primary` 11px). "추천" 배지는 기존대로 정렬 1순위에 붙는다.
- 미리보기: 같은 규칙으로 PDF를 만들어 **새 탭**에 연다(여러 장이면 현재 용지 계획 그대로 + 조립 안내도). 팝업 차단을 피하려고 클릭 순간 빈 탭을 먼저 열고 PDF가 준비되면 주소를 바꾼다. 탭이 막히면 토스트로 알린다.

### 3.5 인스펙터 (U6) — `Inspector.tsx`

- 행 규칙(모든 섹션 공통): `grid-template-columns: 72px minmax(0, 1fr)`, 열 간격 8px, 최소 높이 36px, 세로 가운데 정렬. 라벨은 13px 500 `--c-text-2`, 왼쪽 정렬. 컨트롤은 컨트롤 열 폭을 **꽉 채운다**(드롭다운·세그먼트·입력 모두). 토글만 왼쪽 정렬.
- 섹션: 위아래 패딩 16px, 섹션 사이 1px `--c-border` 구분선. 제목 15px 600 + 아래 12px.
- 섹션 순서와 내용:
  1. 선택 항목(선택 시만): 제목 옆에 항목 이름 칩. 타일 = 회전(세그먼트 4칸, 폭 채움)·좌우 반전·삭제. 오브젝트 = 위치[X|Y]·크기[너비|높이]·회전. 글자 = 글자·크기·색·선 위 흰 글씨·회전. 곡선 = 선 굵기·도형별 수치·정점 수·총 길이·닫힌 경로·삭제.
  2. 맵 크기: 가로 [− n +] 칸, 세로 [− n +] 칸, 아래에 실물 크기 "250 × 200 mm"(12px `--c-text-3`, 컨트롤 열에 맞춤). 칸 크기·선 굵기는 "세부 설정" 접힘 영역 안(기본 접힘). 기본값과 다르면 경고는 접힘과 무관하게 보인다.
  3. 용지: 용지[드롭다운], 방향[가로|세로], 나눔 = 분할 도식(맵 비율 그대로 폭 100% 최대 높이 96px, 왼쪽 정렬, 종이마다 칸 + "행-열" 번호, 이음매 파선. 1장이면 "1장") + 요약 "A4 가로 2장 · 이음매 1곳", "출력 계획기 열기" 버튼(폭 채움).
  4. 검증: 기존 유지.
- 용어: 열→가로, 행→세로, 피치→칸 크기, 선폭→선 굵기. "분할 방식" 행은 삭제(U4).

### 3.6 팔레트 머리글 (U7) — `PalettePanel`

- 모든 도구 공통 머리글: 아이콘 칩 36×36px(`--c-primary-soft` 배경, `--c-primary` 아이콘 20px, 반경 `--r-md`) + 오른쪽에 제목(15px 600)과 설명 한 줄(12px `--c-text-2`). 패딩 16px 16px 12px. 세로 가운데 정렬 금지 — 항상 패널 맨 위.
- 그 아래 도구별 내용, 도움말 상자는 모두 같은 모양(배경 `--c-surface-2`, 패딩 12px, 반경 `--r-md`, 12px 글자)으로 맨 아래.

### 3.7 툴팁 (U8)

- `.bubble`에 `width: max-content; max-width: 240px`. 한 줄 글자는 줄바꿈되지 않는다.

### 3.8 시작 화면 (U9)

## 4. 검토

- 바꾸면 안 되는 값(칸 50mm·선 8mm·이음매는 칸 경계) — 종이 붙이기는 칸 단위로만 늘리므로 이음매는 항상 칸 경계. 경계 표시는 출력 계획기와 같은 함수를 써서 화면·PDF 일치.
- 실행취소 이원화 규칙: 종이 붙이기·인스펙터 스테퍼는 단발 편집이므로 `commitDoc()`만 쓴다.
- 선택 상태: 크기 변경은 인덱스를 바꾸므로 조작 뒤 `setSelection(null)`.
- 예전 파일 호환: 스키마 변경 없음. `print.layout`은 계속 저장하되 인쇄 판단에는 쓰지 않음.
