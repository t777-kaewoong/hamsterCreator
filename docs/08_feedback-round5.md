# 08. 사용자 후기 5차 — 도구 레일 배치·펜 통합·이름 붙여 놓기 (2026-10-27)

> 순서: 원인 분석·조사 → 해결 방향·명세 → 검증. docs/07 다음 회차입니다.

## 1. 후기와 원인

| # | 후기 | 원인(코드 확인) |
|---|---|---|
| 1 | 자유 그리기도 펜 쪽에 넣기 | 자유 그리기(D)가 펜(P)과 따로 레일 버튼. 펜에는 직선/곡선 모드가 이미 있어 같은 "선 긋기"가 두 군데로 갈림 |
| 2 | 지우개를 펜 근처로 | 지우개가 레일 맨 아래 별도 묶음. 선을 긋다 고칠 때 손이 레일 끝까지 내려가야 함 |
| 3 | 장애물 등 글씨를 사이드바(팔레트)에서 고쳐서 붙이기 | 이름은 놓은 **뒤에** 오른쪽 인스펙터에서만 바꿀 수 있음. 같은 이름(예: "1번 컵")을 여러 개 놓으려면 하나씩 다시 고쳐야 함. 출발 이름표는 "출발" 고정 |
| 4 | 레일 버튼 배치가 불편 — 유사 프로그램 조사 후 반영 | 아래 §2 조사 |

## 3. 해결 방향·명세

### 3.1 레일 새 배치(위 → 아래, 구분선 3개)

| 묶음 | 버튼(단축키) |
|---|---|
| ① 고르기 | 선택 V |
| ② 길 그리기 | 격자선 L · 펜 P(직선·곡선·자유) · 도형 O · **지우개 E** |
| ③ 꾸미기 | 타일 B · 타일 집기 I · 글자 T |
| ④ 미션 | 출발·도착 M(장애물 포함) |

- 버튼마다 **아이콘 + 이름**: 버튼 56×50px, 아이콘 20px, 이름 11px(`t-micro`, 600), 아이콘-이름 간격 3px. 레일 폭 64px 그대로. 이름: 선택 / 격자선 / 펜 / 도형 / 지우개 / 타일 / 집기 / 글자 / 출발·도착.
- 툴팁은 단축키 안내용으로 남김(이름이 보이므로 툴팁 의존 없음).

### 3.2 펜에 자유 그리기 넣기
- 펜 팔레트 모드 3개: **직선 / 곡선 / 자유**. 자유 = 예전 자유 그리기(끈 궤적대로).
- D 키는 펜의 자유 모드로, P는 펜의 마지막 직선·곡선 모드로. 레일의 펜 버튼은 세 모드 어느 것이든 켜짐 표시.
- 내부적으로 자유 모드는 기존 자유 그리기 동작을 그대로 씁니다(저장 형식 변화 없음).

### 3.3 이름을 먼저 정하고 붙이기(팔레트)
- 출발·도착·장애물 팔레트에 **"붙일 이름"** 칸:
  - 출발: 자리표시 "출발". 놓으면 그 이름표. (`StartMarker.name?` 추가 — 없으면 "출발")
  - 도착: 자리표시 "자동(도착1…)". 놓은 뒤 칸을 비움(같은 이름 도착지가 겹치지 않게).
  - 장애물: 자리표시 = 종류 이름(종이컵 등). 칸에 적은 이름이 계속 유지돼 같은 이름을 여러 개 연달아 놓을 수 있음. 종류를 바꾸면 비움.
- 놓은 뒤에 고치는 것은 지금처럼 인스펙터(출발에도 이름 칸 추가).

## 4. 검증 (2026-10-27)

- `npx tsc -b` 0건, `npm run build`·`build:single` 성공, 크기 변경 회귀 31항목 통과.
- 개발 서버(1440×900): 레일 순서·이름 "선택 / 격자선 · 펜 · 도형 · 지우개 / 타일 · 집기 · 글자 / 출발·도착" 화면 확인.
- D 키 → 펜 자유 모드(내부 freeDraw), P 키 → 펜 곡선 모드, 자유 모드에서 다른 도구로 갔다가 레일 펜 버튼 → 자유 모드로 복귀. 펜 팔레트 모드 3개(직선·곡선·자유).
- 붙일 이름(합성 클릭): 출발 "집" → 이름표·인스펙터 이름 칸 "집". 도착 "도서관" → 놓은 뒤 칸 비워짐. 장애물 종류 변경 시 칸 비워짐, "컵 A"로 소주컵 2개 연달아 → 둘 다 "컵 A". 자리표시: 장애물 = 종류 이름, 출발 = "출발".
- 한계: 실제 마우스로 그리는 모습은 미리보기 창이 가려져 눈으로 확인하지 못함.
