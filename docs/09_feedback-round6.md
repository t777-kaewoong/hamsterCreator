# 09. 사용자 후기 6차 — 선에 걸쳐 놓기·종이별 격자선·이미지 바뀜 오류·선 위/아래 (2026-10-27)

> 순서: 원인 분석 → 해결 방향·명세 → 검증. docs/08 다음 회차입니다.

## 1. 후기와 원인

| # | 후기 | 원인(코드 확인) |
|---|---|---|
| 1 | 도형·이미지도 선에 반 걸쳐 놓기(꼭 네모 안에만이 아님) | 타일·이미지는 칸(50mm)에 딱 맞춰서만 찍힘. 자유 배치는 Alt에 숨어 있고, 선택 도구로 칸 타일을 끌면 칸 단위로만 옮겨짐. 도형은 1mm 자유라 선·칸에 맞춰 정렬할 기준이 없음 |
| 2 | 격자선을 원하는 종이에만 | 팔레트의 "경계 전체에 넣기"는 맵 전체 바깥 경계에 진입로를 넣음. 격자선을 종이 한 장 단위로 채우거나 비우는 방법이 없음 |
| 3 | 이미지를 놓고 새 이미지를 추가하면 기존에 놓은 이미지가 새 이미지로 바뀜 | **초안(localStorage)에 이미지가 빠져 있음**(용량 때문, draft.ts). 초안을 "복구"하면 칸은 asset:u1을 가리키는데 u1 그림이 없음 → 다음에 올린 이미지가 비어 있던 u1 번호를 받아 기존 칸이 전부 새 그림이 됨. 이미지를 올리는 동작 자체는 초안 저장도 하지 않았음 |
| 4 | 타일과 선의 위아래 설정 | 2026-09-29부터 모든 타일·이미지가 선 위로 고정(isTileAboveLine). 바닥 무늬처럼 선이 위로 보여야 하는 경우를 고를 수 없음 |

## 2. 해결 방향·명세

### 2.1 놓는 자리 (1)
- 타일 팔레트에 **"놓는 자리"** 3칸 선택(그림 버튼): **칸에 맞춤**(기존) / **반 칸(25mm)** / **자유**.
  - 반 칸: 그림 중심이 25mm 격자점에 붙음 → 칸 가운데·선 위·선이 만나는 곳·칸 경계 어디든 정확히 걸쳐 놓임.
  - 반 칸·자유로 놓은 그림은 자유 배치 그림(props, 50×50mm)이 되어 선택 도구로 옮기고 크기를 바꿀 수 있음.
  - Alt는 이번만 "자유", Shift+드래그 영역 채우기는 늘 칸 단위.
- 칸 타일 인스펙터에 **"칸에서 떼기"** 버튼: 같은 자리의 자유 배치 그림으로 바꿔, 끌어서 선에 걸쳐 옮길 수 있게 함.
- 도형 팔레트에 **"반 칸 격자에 맞추기"** 토글(기본 끔): 켜면 도형을 그릴 때 시작·끝 모서리가 25mm 격자에 붙어 선·칸에 딱 맞춰 그려짐.

### 2.2 종이별 격자선 (2)
- 격자선 팔레트에 **종이 고르기 도식**(인쇄 분할과 같은 종이 번호 1-1, 1-2 …, 화면 종이 경계와 같은 계산). 한 장을 누르면 고름.
- 고른 종이에 대해: **격자선 채우기** / **진입로 넣기**(그 종이에 걸친 맵 바깥 경계만) / **비우기**(그 종이 안 선·진입로).
  - 채우기는 종이 안 격자점끼리 잇고, 이웃 종이에 이미 선이 있는 격자점과는 이음매를 건너 이어 줌(끊김 없게).
- 맵 전체 버튼은 "모든 종이"라는 이름으로 남김.

### 2.3 이미지 바뀜 오류 (3)
- 초안의 이미지를 IndexedDB에 초안 id별로 보관(`lib/storage/draftAssets.ts`), 복구할 때 다시 붙임. 초안을 지우거나 오래된 초안이 밀려나면 그 이미지도 정리.
- 이미지를 올리는 순간에도 초안 저장.
- 새 이미지 번호는 그림이 없어도 칸·자유 배치 그림이 아직 가리키는 번호를 건너뜀(이미 깨진 초안에서도 덮어쓰기 없음).

### 2.4 선 위/아래 (4)
- `Cell.under?`, `Prop.under?`(선택 필드, 없으면 선 위 = 지금과 같음).
- 타일 팔레트 토글 **"선 아래에 깔기"**: 켜고 놓으면 선이 그림 위로 보임.
- 선택한 칸 타일·그림의 인스펙터에 **"선과의 순서: 선 위 / 선 아래"** 두 칸 선택.
- 화면·PDF·썸네일 모두 같은 규칙: 선 아래 칸 타일 → 선 아래 그림 → 곡선 → 격자선 → 선 위 칸 타일 → 선 위 그림 → 글자 …

## 3. 검증 (2026-10-27)

- `npx tsc -b` 0건, `npm run build`·`build:single` 성공, 크기 변경 회귀 31항목 통과.
- **이미지 바뀜(3)** 실제 흐름으로 재현·확인: 빨간 이미지 올림 → 칸 2개에 놓음 → 새로고침 → "복구" → userAssets u1(빨강) 그대로 돌아옴 → 파란 이미지 올림 → u2, 기존 칸은 u1 유지. 그림 없이 칸만 u1을 가리키는 깨진 상태에서도 새 이미지 번호는 u3(덮어쓰기 없음). (수정 전에는 초안 복구 뒤 userAssets가 비어 다음 이미지가 u1을 받았음)
- **놓는 자리(1)**: 자유 → 클릭 자리 그대로(40,40), 반 칸 → (63,41)을 눌러 중심 (75,50)에 50×50 그림. 칸 타일 "칸에서 떼기" → 같은 자리(100,100) 그림으로 바뀌고 선택됨.
- **선 위/아래(4)**: "선 아래에 깔기" 켜고 칠한 칸 → `under: true`. 인스펙터 "선과 순서" 선 위로 바꾸면 under 없어짐. 화면 아트 레이어·PDF가 under 칸·그림을 격자선보다 먼저 그림.
- **종이별 격자선(2)**: A4 2장(10×4)에서 1-2 비우기 → 1-1 선 16·15개만 남고 이음매 선도 지워짐. 1-2 채우기 → 1-1에 선이 있어 이음매까지 이어져 원래 36·30개로 복구. 빈 맵에서 1-2만 채우기 → 1-2 안만(가로 시작 열 5), 진입로 넣기 → 1-2 바깥 테두리 14개만. 팔레트 도식 "1-1 / 1-2" 화면 확인.
- 참고: 전체 격자 맵에 종이를 붙이면 새 종이도 격자로 채워지는 기존 동작(2026-09-28 결정)은 그대로이고, 원치 않으면 그 종이를 "비우기"로 지울 수 있습니다.
- 한계: 실제 마우스로 끄는 모습은 화면이 가려져 일부만 확인.
