# 12. 사용자 후기 9차 — 글자 입력·타일 크기·교통 표지판·소방 타일 (2026-10-29)

> 순서: 원인 분석 → 해결 방향·명세 → 검증. docs/11 다음 회차입니다.

## 1. 후기와 원인

| 후기 | 원인(코드 확인) |
|---|---|
| 글자 입력이 너무 불편함. 줄바꿈이 안 되고, 뭐라고 쓰는지 보이지 않음 | 입력창이 한 줄 `<input>`(Enter = 확정)이라 줄바꿈 불가. 입력창이 글자 자리 **위에** 덮여 실제 글자를 가렸고, 확정 전에는 캔버스 글자가 바뀌지 않았음. 그리기·PDF도 한 줄만 처리 |
| 타일 크기를 조절하고 싶음 | 칸 타일(cells)은 항상 1칸. 자유 배치 그림(props)은 크기를 바꿀 수 있었지만, 먼저 "칸에서 떼기"를 해야 해서 찾기 어려웠음 |
| 빨간 원 + 숫자 교통 타일 몇 가지, 숫자는 직접 입력 | 교통 테마가 없음 |
| 보내 준 그림 5장을 '소방' 타일로 | 소방 테마가 없음 |

## 2. 해결 방향·명세

### 2.1 글자 입력 (여러 줄 + 바로 보기)
- 글자 도구로 누르면 **글자 바로 아래에 편집 카드**가 뜸(폭 280px, 16px 글씨, 줄 수만큼 늘어나고 200px 넘으면 스크롤). 카드가 캔버스 글자를 가리지 않음.
- **입력하는 대로 캔버스 글자가 바뀜**(doc을 조용히 갱신, 실행취소 기록은 확정할 때 한 번).
- 키: **Enter = 줄바꿈**, **Ctrl(⌘)+Enter 또는 "완료" 단추 또는 바깥 클릭 = 완료**, Esc = 취소(새 글자는 지우고, 고치던 글자는 원래대로).
- 여러 줄 규칙(`src/lib/model/labelText.ts`): 줄 간격 = 글자 크기 × 1.25, 줄 묶음 전체의 가운데가 라벨 좌표. 화면·클릭 판정(가장 긴 줄 폭 × 줄 높이)·PDF가 같은 규칙.
- 인스펙터 "글자" 칸도 여러 줄 입력창.

### 2.2 타일 크기
- 팔레트(타일 도구) **"크기(칸)" ½ · 1 · 1½ · 2 · 3** (`editorStore.stampScale`, 1칸 = 50mm).
- 1칸이 아니면 자유 배치 그림으로 놓임. "놓는 자리 = 칸"일 때 자리 맞추기(`tileScale.snapScaledCenter`):
  - 2·3칸: 왼쪽 위 모서리를 칸 경계에 붙여 정확히 2×2·3×3칸을 덮음. 가장자리를 눌러도 종이 밖으로 안 나가게 안으로 밀어 넣음.
  - ½·1½칸: 중심을 25mm 격자점(칸 가운데·모서리)에 붙임.
  - 반 칸·자유 모드는 기존 규칙 그대로, 크기만 따름. 미리보기(고스트)도 고른 크기로.
- 인스펙터: 칸 타일에 "크기(칸)" — 1 외를 누르면 그림으로 바꾸며 키움(2·3칸은 이 칸이 왼쪽 위, ½·1½은 이 칸 가운데). 그림에도 "크기(칸)" — 가운데 유지, 긴 변을 그 칸 수로(비율 유지).

### 2.3 교통 테마(9종) + 숫자 표지판
- 내장: 제한속도 30·40·50·60·80·100, 진입금지, 통행금지, 정지. 흰 원 + 빨간 테두리 + 검은 굵은 숫자(사용자가 보낸 예시와 같은 모양)로 직접 그림.
- 교통 탭(및 "전체"의 교통 묶음) 위에 **숫자 표지판 만들기**: 미리보기 원 + 숫자 칸(1~3자리) + "만들기". 그 자리에서 같은 모양을 그려 내 이미지(userAssets)에 넣고 바로 타일로 고름(`src/lib/tiles/speedSign.ts`). 같은 숫자는 한 번만 저장.

### 2.4 소방 테마(5종)
- 경광등·소화전·소방차·구급차·119 안전센터. 테두리에 이어진 흰 배경만 투명하게, 433px 칸에 맞춤, 256색으로 줄임(장당 24~40KB).
- 출처는 `src/assets/NOTICE.md` §1-1·1-2.

## 3. 검증 (2026-10-29)

- `npx tsc -b` 0건, `npm run build` 성공, 크기 변경 회귀 31항목 통과.
- 개발 서버(A4 기본):
  - 글자: 새 글자에 "출발선⏎여기서 시작" 입력 → 캔버스에 두 줄이 바로 보이고 카드는 아래에 뜸. 새 글자 Ctrl+Z 한 번에 사라짐. 기존 글자를 고쳐 Ctrl+Enter → 실행취소 한 번에 원래 글자. 고치다 Esc → 원래 글자.
  - 크기: 숫자 표지판 25 만들기 → 내 이미지에 들어가 선택됨. 1칸은 칸 타일, 2칸 소방차를 오른쪽 위 가장자리에 놓으면 (150,0) 100×100으로 종이 안. 칸 타일을 인스펙터 1½로 → 그림 75×75.
  - PDF: 두 줄 글자 + 교통 타일이 든 문서로 `generateSingleSheetPdf` 오류 없이 생성.
  - 콘솔 오류 0건.
