## 1. 후기와 원인

| # | 후기 | 원인(코드 확인) |

## 2. 해결 방향

### 2.1 좌측 도구 묶음 (11, 6, 12)

구분선으로 5묶음. 위에서 아래로:

| 묶음 | 도구(단축키) |
|---|---|
| ① 고르기 | 선택 V |
| ② 길 그리기 | 격자선 L · 펜 P · 자유 그리기 D · 도형 O |
| ③ 꾸미기 | 타일 B · 타일 집기 I · 글자 T |
| ④ 미션 | 출발·도착·장애물 M |
| ⑤ 지우기 | 지우개 E |

- "영역 채우기(R)" 도구는 없앰 → 타일(B) 안으로(§2.2). 도구 수 11 → 10.
- R 키는 이제 언제나 "회전"(타일 도구일 때). 도구 전환과의 충돌 예외 코드 삭제.

### 2.2 타일 도구 하나로 (6)

| 조작 | 동작 |
|---|---|
| 클릭·드래그 | 칸에 칠하기(기존) |
| **Shift + 드래그** | 사각 영역 채우기(기존 R 도구, "3 × 4" 칩 미리보기) |
| **Alt + 클릭·드래그** | 격자 무시 자유 배치(기존 Shift 동작을 옮김) |
| 우클릭 | 같은 타일 다시 찍기(기존) |
| R / F | 회전 / 좌우 반전(기존) |

- Shift를 영역 채우기에 쓰므로 자유 배치는 Alt로 옮깁니다. Alt는 출발·도착·장애물에서도 "격자에 안 붙이기"라 의미가 같아집니다(§2.6).
- 무작위 채우기(기존 Alt+R)는 팔레트의 토글 "같은 테마 섞어 칠하기"로 바꿈. 켜면 칠하기·영역 채우기 모두 같은 테마 타일을 무작위로 섞음.
- 팔레트 아래 조작법은 글 대신 **키 칩 + 짧은 설명** 5줄(§3.3).

### 2.3 종류 '전체' (7)
- 종류 목록 맨 앞에 '전체'. 기본값. 테마별 소제목(던전·숲 …·아이콘·내 이미지)으로 나눠 한 그리드에 다 보여 줌.
- 타일 집기로 고르면 '전체'일 때는 종류를 바꾸지 않고 그 타일로 스크롤만 함.

### 2.4 선 그리기 정리 (5, 12, 17, 3)

검토 결론: **격자선과 펜은 합치지 않습니다.** 둘은 데이터가 다릅니다.
- 격자선(L) = 격자점끼리만 잇는 선. 로봇이 "한 칸 앞으로" 단위로 움직이는 길이고, 검증·정답 코드가 이것만 읽음.
- 펜(P) = 아무 데나 긋는 선. 라인트레이서용 트랙이라 칸 계산에 쓰지 않음.

대신 겹쳐 보이던 원인(직선을 그릴 도구가 없어 격자선으로 해결하려 함)을 없앱니다.
- 펜에 **직선 / 곡선** 모드. 직선 모드는 클릭마다 꺾인 직선(꺾은선), 한 번 끌면 직선 하나.
- 직선 모드에서 끝점이 격자점 5mm 안이면 격자점에 붙음(격자선과 이어 그리기 쉬움). Alt를 누르면 안 붙음.
- **Shift**: 직전 점에서 0°·45°·90° … 방향으로 고정(펜 두 모드, 자유 그리기 제외).
- 도형(O)에서 "직선"은 뺌(원·타원·라운드 사각 3종). 예전 파일의 직선은 그대로 열리고 편집됨.
- 도형도 Shift = 정원·정사각.
- 머리글 설명에 차이를 한 줄로: 격자선 "로봇이 칸 단위로 다니는 길(정답 계산에 쓰임)", 펜 "아무 데나 긋는 트랙 선".

### 2.5 선택 도구로 옮기기·크기·복사 (1, 2, 4, 10, 13)

- **끌어서 옮기기**: 도형·곡선·그림·글자·장애물은 mm 단위로, 칸 타일은 다른 칸으로(놓을 칸에 있던 타일은 바뀜). 끌기 한 번 = 실행취소 한 단계.
- **크기 핸들**: 원(4모서리, 비율 고정), 타원·라운드 사각·그림(4모서리 + 4변), 장애물(4모서리 = 지름). 맞은편 모서리·변이 고정. Shift = 비율 유지. 최소 4mm.
- 커서: 핸들 위 ↔/↕/⤡, 대상 위 이동(move).
- **복사**: Ctrl+드래그 = 복제해서 옮기기(원본 유지, 파워포인트와 같음). Ctrl+C / Ctrl+V(커서 위치에, 커서가 캔버스 밖이면 10mm 옆), Ctrl+D(10mm 옆 복제).
- **도형을 그리면 선택 도구로** 바뀌고 방금 그린 도형이 선택됨 → 곧바로 옮기기·크기 조절 가능.
- **정수 mm**: 도형 생성·이동·크기 조절, 펜 정점, 자유 그리기 정점, 장애물·자유 위치 마커는 1mm 단위로 반올림. 원은 지름을 정수로. 인스펙터 숫자 칸은 소수 첫째 자리까지만 표시(예전 파일의 긴 소수 대비).

### 2.6 출발·도착 모양·자유 위치, 장애물 (8, 9, 14, 16)

M 도구 팔레트: 종류 3개 **출발지 / 도착지 / 장애물**.

- 모양: 출발·도착 모두 **기본 / 햄스터** 두 가지 그림 버튼. 고르면 지금 있는 출발(또는 모든 도착)에 바로 적용되고 이후 놓는 것도 그 모양. 햄스터는 위에서 내려다본 로봇(바퀴 2·눈 2)이고, 출발은 출발 방향을, 도착은 위쪽을 봄.
- **Alt + 클릭 = 자유 위치**(격자점에 안 붙음). 정답 코드·검증은 가장 가까운 격자점으로 계산(안내 한 줄).
- 장애물: 종이컵 Ø70 / 소주컵 Ø50 / 병뚜껑 Ø30(지름은 인스펙터에서 변경). 점선 원 + 가운데 이름. 클릭 = 가장 가까운 격자점(칸 중심)에, Alt = 자유. 여러 개 가능. 장애물 중심 8mm 안을 다시 누르면 삭제. 선택 도구로 옮기기·크기, 지우개로 지우기 가능.
  - 지름 근거: 종이컵(6.5oz 자판기컵) 입구 70mm·바닥 52mm — 엎어 놓는 경우가 많아 큰 쪽. 소주잔 입구 약 48mm. 병뚜껑(PET·소주) 약 30mm.

### 2.7 저장 버튼 (15)
- "저장" 하나 + 오른쪽에 붙은 ▾ 버튼. ▾를 누르면 "다른 이름으로 저장(Ctrl+Shift+S)" 메뉴. 같은 버튼 둘처럼 보이지 않음. 덮어쓰기가 안 되는 브라우저(내려받기)에서는 ▾ 없음(기존과 같음).

### 2.8 맵 밖 (19)
- 펜·자유 그리기·도형 입력 좌표는 종이 안으로 제한.
- 화면도 PDF처럼 종이 밖은 잘라서 그림(아트·선·그림·글자·마커 레이어). 화면에서 본 그대로 인쇄됨.

### 2.9 인쇄 이음매 (18, 20)

**맞대기**
- 재단 점선·모서리 마크·정렬 삼각형은 **이웃 장과 맞닿는 변에만**. 바깥 변에는 아무것도 없음(자를 필요 없음).

**겹치기** — 원리부터 바로잡음
- 프린터는 종이 끝 4~5mm를 못 찍으므로 모든 종이에 흰 테두리가 남습니다. 그래서 위에 얹는 장의 이음 변은 한 번은 잘라야 합니다(가위질 0번은 물리적으로 불가). 대신 **이음매 하나당 가위질 1번, 정확히 안 잘라도 됨**이 겹치기의 의미입니다.
- 아래 깔리는 장(왼쪽·위쪽): 이음 변을 **자르지 않음**. 겹칠 띠(겹치기 폭)를 옅은 보라 빗금으로 표시하고 "다음 장이 덮는 곳 · 풀칠" 표시.
- 위에 얹는 장(오른쪽·아래쪽): 이음 변에 "여기를 자르세요" 점선을 원래 경계에서 겹치기 폭의 절반 안쪽에 긋고, 그 양옆 겹치기 폭만큼을 "자를 수 있는 범위"로 표시. 범위 안 어디를 잘라도 아래 장의 같은 그림이 보이므로 이음이 어긋나지 않음.
- 조립 안내 문구도 방식별로 다르게.

## 3. 명세 수치

### 3.1 데이터(PRD §5 확장, 모두 선택 필드 — 예전 파일 그대로 열림)
- `StartMarker.at?: [x, y]`, `GoalMarker.at?: [x, y]` — 자유 위치(mm). 없으면 `cell`의 격자점. `cell`은 항상 가장 가까운 격자점으로 같이 저장.
- `StartMarker.look?`, `GoalMarker.look?`: `'basic' | 'hamster'`. 없으면 basic.
- `MapDoc.obstacles?: { kind: 'paperCup' | 'sojuCup' | 'bottleCap'; cx; cy; d }[]` (mm).
- 크기 변경(종이 붙이기·떼기)은 장애물·자유 위치 마커도 같이 옮기고, 종이 밖으로 나간 것은 지움.

### 3.2 햄스터 마커 그림(mm, 마커 중심 기준, 위를 보는 모습, 방향에 따라 회전)
- 몸통: 30×32 둥근 사각(모서리 7), 흰 채움, 테두리 2.5 #111.
- 바퀴: 양옆 x=±17, 5×16 검정 채움(모서리 1.5).
- 눈: 앞쪽 (±6.5, −8), 지름 5 검정.
- 방향 표시: 몸통 안 위를 향한 삼각형, 꼭짓점 (0, 1)·밑변 (±5, 9).
- 이름표(출발·도착 이름)는 기존과 같이 아래에.

### 3.3 팔레트 조작법 키 칩
- 줄 높이 24px, 키 칩: 높이 20px, 좌우 패딩 6px, 테두리 1px `--c-border`, 모서리 4px, `t-micro` 600. 설명은 `t-caption`.
- 타일: [클릭·드래그] 칠하기 / [Shift]+드래그 영역 채우기 / [Alt] 자유 배치 / [R] 회전 · [F] 반전 / [우클릭] 같은 타일 찍기
- 펜: [Enter]·더블클릭 완료 / [Esc] 취소 / [Shift] 각도 고정 / [Alt] 격자점에 안 붙이기(직선)
- 선택: 끌기 옮기기 / 핸들 크기 / [Ctrl]+끌기 복제 / [Ctrl]+[C]·[V] 복사·붙여넣기 / [Delete] 삭제
- 출발·도착·장애물: [Alt]+클릭 자유 위치

### 3.4 선택 핸들
- 핸들 8px 정사각, 흰 채움, 1.5px `--c-primary`(기존 장식 값 그대로). 잡는 범위 반경 7px(화면).
- 끌기 시작 기준 3px(기존 CLICK_THRESHOLD_PX).

### 3.5 장애물 그림
- 점선 원: 선 1.2mm #111, 점선 4mm·틈 2.5mm. 가운데 이름 5mm, #444, 흰 후광 1.2mm.

### 3.6 겹치기 PDF 표시
- 겹칠 띠: rgb(0.31, 0.275, 0.898) 불투명도 0.10 채움 + 같은 색 0.25mm 실선 테두리, 띠 가운데 세로/가로 글자 "다음 장을 여기에 겹쳐 붙이세요" 2.2mm.
