# 07. 사용자 후기 4차 — 장애물 이름·출발/도착 자유 위치·내 타일 이미지 (2026-10-27)

> 순서: 원인 분석 → 해결 방향·명세 → 검증. docs/06 다음 회차입니다.

## 1. 후기와 원인

| # | 후기 | 원인(코드 확인) |
|---|---|---|
| 1 | 장애물에 적힌 명칭을 수정하고 싶음 | 이름이 종류(종이컵·소주컵·병뚜껑)에서 고정으로 나옴. 데이터에 이름 칸이 없음 |
| 2 | 출발지·도착지를 자유 위치에 놓고 싶음(칸 걸치기가 안 됨) | 자유 위치는 **Alt+클릭**에만 숨어 있었음(팔레트에 키 칩 한 줄). 놓은 뒤 옮기는 방법이 없음 — 선택 도구가 출발·도착을 잡지 못하고, 다시 놓는 수밖에 없었음 |
| 3 | 타일에 원하는 이미지를 추가하고 싶음 | 기능은 있으나(종류 "내 이미지" → 이미지 추가) **기본 종류 '전체'에서는 올릴 곳이 보이지 않음**: '전체'는 올린 이미지가 있을 때만 "내 이미지" 묶음을 보여 주고, 추가 버튼은 종류를 "내 이미지"로 바꿔야 나타남. 또 올린 이미지는 그 맵 파일에만 들어 있어 새 맵에서는 다시 올려야 함 |

## 2. 해결 방향·명세

### 2.1 장애물 이름 (1)
- `Obstacle.name?: string` 추가(선택 필드). 없으면 종류 이름을 씁니다. 빈 글자면 이름 없이 점선만 찍습니다.
- 인스펙터 장애물 섹션에 "이름" 줄(입력을 마치면 저장 = 실행취소 1단계). 자리표시 글자는 종류 이름. 오른쪽 작은 버튼 "기본 이름" → 이름 칸을 지워 종류 이름으로 되돌림.
- 화면·PDF·인스펙터 칩이 모두 같은 함수(`obstacleLabel`)로 이름을 정합니다.

### 2.2 출발·도착 자유 위치 (2)
- **팔레트 토글 "격자점에 붙이기"**(출발·도착·장애물 공통, 기본 켬). 끄면 누른 자리 그대로(1mm 단위) 놓입니다. Alt는 토글의 반대로 동작(켜져 있으면 자유, 꺼져 있으면 붙이기).
- **선택 도구로 끌어 옮기기**: 출발·도착을 눌러 고르고 끌면 자유롭게 옮겨짐(칸 경계에 걸쳐도 됨). 격자점 4mm 안으로 가져가면 격자점에 딱 붙음(자유 위치 해제). 끌기 한 번 = 실행취소 한 단계.
  - 잡는 범위: 기본 모양 지름 34mm 원, 햄스터 모양은 사진 범위(43.6×45mm). 출발·도착은 화면 맨 위에 그려지므로 다른 것보다 먼저 잡힘.
  - 선택 윤곽은 핸들 없는 사각형(크기 조절 없음). Delete로 삭제, 지우개로도 지움.
- **인스펙터 "선택 항목"**: 출발 = 방향(위·오른쪽·아래·왼쪽) / 모양(기본·햄스터) / 위치 X·Y(mm) / "격자점에 맞추기" 버튼 / 삭제. 도착 = 이름 / 모양 / 위치 / 격자점에 맞추기 / 삭제.
- 정답 코드·검증은 지금처럼 가장 가까운 격자점(`cell`)으로 계산(자유 위치를 옮길 때마다 `cell`도 갱신).

### 2.3 내 타일 이미지 (3)
- 타일 팔레트 '전체'에 **"내 이미지" 묶음을 항상** 보여 주고, 묶음 끝에 **＋ 칸**(점선 테두리, 77×77px, 가운데 Upload 아이콘 20px + "추가" 글자)을 둡니다. 종류 "내 이미지"의 그리드 끝에도 같은 ＋ 칸. 이미지 파일을 그 칸에 끌어 놓아도 추가됩니다.
- **이 브라우저에 보관(내 이미지 보관함)**: 올린 이미지는 맵 파일(userAssets)과 함께 브라우저 IndexedDB에도 저장해, 새 맵·다른 맵에서도 팔레트에 계속 보입니다. 보관함에만 있는 이미지를 고르거나 끌면 그 순간 맵 파일에 넣습니다(같은 이미지는 중복으로 넣지 않음).
- 내 이미지 칸에 마우스를 올리면 오른쪽 위 × 버튼(18px): 보관함에서 빼고, 지금 맵에서 쓰지 않는 이미지면 맵 파일에서도 뺍니다. 맵에 놓인 그림은 지워지지 않습니다.
- 정사각형으로 잘라 433px 이하로 줄이는 기존 규칙은 그대로(내장 타일과 같은 해상도).
- IndexedDB가 막힌 환경(파일로 연 단일 HTML 등)에서는 보관함 없이 지금처럼 맵 파일에만 넣습니다.

## 3. 검증 (2026-10-27)

- `npx tsc -b` 0건, `npm run build`·`build:single` 성공, 크기 변경 회귀 31항목 통과.
- 개발 서버(합성 포인터 이벤트, 화면 창이 가려져 캔버스는 기본 크기였으나 좌표 환산으로 확인):
  - 격자점에 붙이기 켬 → 격자점 (3,0), 같은 자리 Alt+클릭 → 자유 위치 (159, …). 끔 → 누른 자리 그대로.
  - 선택 도구로 출발을 (75,75)에서 (100,100)까지 끌기 → `at: [100,100]`(네 칸 모서리에 걸침), 선택 = 출발, 실행취소 1단계. (127,77)로 끌기 → 격자점 (125,75)에 붙고 `at` 없어짐. 도착도 (300,150)으로 끌림. 인스펙터에 "격자점에 맞추기" 표시.
  - 장애물 이름 "1번 컵" 입력 → 저장·칩 "장애물 · 1번 컵", "기본 이름" 버튼 표시. 빈 이름 → 이름 없음. 기본 이름 → 종류 이름으로 복귀.
  - 타일 '전체' 맨 위 "내 이미지" + 추가 칸. 파일 입력으로 300×200 PNG 올림 → 맵 파일 u1(200×200 정사각 크롭) + 보관함 저장, 바로 스탬프 선택. 보관함에만 있던 이미지를 누르면 맵 파일 u2로 들어가고 선택됨. 놓지 않은 이미지의 × → 맵 파일·보관함 모두에서 빠짐.
  - 시험용 이미지는 보관함에서 지워 둠(개발 서버 주소의 보관함이라 실서비스와는 별개).
- 한계: 실제 마우스로 끄는 모습·× 버튼 호버 표시는 화면이 가려져 눈으로 확인하지 못함.
