## 2. 해결 방향·명세

### 2.1 시작 화면(애플풍)
- 프리셋 2종: **A4 기본**(5×4, 격자 채움) · **빈 격자**(5×4, 선 없음). 나머지 6종 삭제(코드에서도 제거).
- 배경 `#F5F5F7`, 콘텐츠 최대 폭 720px, 위 여백 `clamp(48px, 12vh, 120px)`.
- 제목 48px/700, 자간 -0.03em, 색 `#1D1D1F`. 부제 없음.
- 카드 2장 가로 배치(간격 24px, 각 1fr), 흰 바탕, 모서리 20px, 그림자 `0 2px 12px rgba(0,0,0,.06)`, 호버 시 `translateY(-4px)` + 그림자 강화. 썸네일 영역 높이 180px(배경 `#F5F5F7`), 이름 17px/600, 규격 13px 회색.
- 파일 열기: 점선 상자 대신 알약 버튼 "말판 파일 열기"(높이 44px) + 그 아래 13px 회색 "또는 .hsmap.json 파일을 창에 끌어 놓기". 창 전체 끌어 놓기는 그대로, 끌고 있을 때는 화면 전체에 옅은 파란 테두리.
- 맨 아래 12px 회색 출처: "햄스터S 자료 출처: 햄스터스쿨(hamster.school) 튜토리얼 · 일부 그림은 AI로 생성했습니다". 링크는 새 탭.

### 2.2 상단바 — 말판 파일과 PDF 구분
- 오른쪽 순서: **[열기] [저장 ▾]** │ [미리보기] [정답] **[PDF 저장]**(유일한 파란 버튼).
- 열기·저장 툴팁: "말판 파일(.hsmap.json) 열기/저장 — 나중에 이어서 고칠 수 있어요". PDF 저장 툴팁: "인쇄용 PDF 파일로 내려받기".
- 열기: 저장 안 된 변경이 있으면 확인 모달("저장하지 않고 열기"). 연 문서는 새 초안 슬롯(App.openDoc 재사용). 열기 단축키 Ctrl+O.
- 내려받기 방식 브라우저에서는 저장 버튼 이름 "저장"(툴팁에 "파일로 내려받음").

### 2.3 PDF 저장 화면(옛 출력 계획기)
- 제목 "PDF 저장", 하단 주 버튼 "PDF 저장".
- 왼쪽 설정 열(폭 300px), 오른쪽 미리보기(기존 시트 나눔 그림 유지).
  1. **용지**: 드롭다운. 순서 A4·A3·A2·A1·A0·B4·B3·B2·B1, 항목 "A4 (297×210mm)". 기본값은 문서 용지(새 문서는 A4).
  2. **방향**: [가로 | 세로]. 용지를 고르면 장수가 적은 쪽(같으면 이음매·낭비 적은 쪽)을 자동 선택하고 그쪽에 "추천" 표시.
  3. 결과 한 줄: "A4 가로 2장 · 이음매 1곳".
  4. **이음매 방식**(2장 이상일 때만): 맞대기 / 겹치기(+ 폭 mm).
  5. **PDF에 넣을 것**: 조립 안내도·맞춤 표시·50mm 확인 자·안내 문구 — 열 때마다 **모두 해제**.
- 크기 입력·정렬·18장 카드 목록 삭제(맵 크기는 인스펙터에서 바꿈).

### 2.4 여러 장 PDF — 가위질 최소화
- 시트를 용지 가운데 두지 않고, **이웃 장과 맞닿는 변을 용지 끝 쪽으로 붙입니다**(끝에서 6mm, 프린터가 찍을 수 있는 한계).
  - 가로: 왼쪽에 이웃이 있으면 맵 왼쪽 = 6mm. 왼쪽 이웃 없이 오른쪽에만 이웃이 있으면 맵 오른쪽 = 용지폭 − 6mm. 이웃이 없으면 가운데.
  - 세로도 같은 규칙(위·아래).
- 붙이는 규칙 하나: **오른쪽·아래 장을 왼쪽·위 장 위에 얹는다.** 그래서 자르는 곳은 "얹는 장의 왼쪽·위 변" 하나뿐이고, 그 띠는 6mm라 가위 대신 접어 넘겨도 됩니다. 깔리는 장의 남는 여백은 얹는 장에 덮여 자를 필요가 없습니다.
- 자를 변 표시는 체크와 무관하게 **항상** 그립니다(점선 + "✂ 자르기" 대신 글자 "자르기"): 맞대기는 맵 경계, 겹치기는 겹치기 폭 가운데. 깔리는 장의 이음 변에는 옅은 "여기에 겹쳐 붙이기" 띠(겹치기)/경계선(맞대기).
- 시트 번호(1-1 등)도 여러 장이면 항상 찍습니다(순서를 모르면 붙일 수 없음). "안내 문구" 체크는 "실제 크기로 인쇄" 문구만.
- 조립 안내도 문구도 이 규칙으로 교체.

### 2.5 격자선 긋기
- 팔레트 맨 위에 **[긋기 | 지우기]** 전환(크게, 아이콘 포함). Alt는 누르는 동안만 반대 동작(그대로).
- 커서를 올리면 **누르면 바뀔 토막을 미리** 보여 줌: 그을 때 파란 반투명, 지울 때 빨간 반투명. 가장 가까운 격자점에 작은 점 표시.
- 팔레트 설명을 그림 3개로: ① 점→점 끌기 = 선 ② 선 한 번 누르기 = 켜기/끄기 ③ 바깥 반 칸 누르기 = 진입로.
- "한꺼번에" 단추는 그대로(전체 채우기·진입로·비우기).

### 2.6 출발·도착 크기
- `StartMarker.scale?`, `GoalMarker.scale?`(기본 1, 범위 0.5~2). 예전 파일은 값이 없어 그대로 열림.
- 선택(V)하면 모서리 핸들 4개. 끌면 **중심 고정**으로 비율 유지 확대·축소. 끌기 한 번 = 실행취소 한 칸.
- 인스펙터 "크기" 슬라이더 50~200%(5% 단위) + "실물 크기" 단추(100%로). 햄스터 100% = 실제 로봇 40mm.
- 화면·PDF·선택 상자·클릭 판정 모두 같은 배율. 이름표 글자 크기는 그대로, 위치만 몸통 아래로 따라감.

### 2.7 아이콘

### 2.8 정답
- 격자 탭: 경로·코드 대신 안내 카드 "기능 구현중 — 타일·장애물을 인식하는 격자 정답은 준비 중이에요". 격자 정답 복사·PDF 단추 비활성. 라인트레이서 탭은 그대로.
- 원래 코드는 `GRID_ANSWER_READY` 한 값으로 되살릴 수 있게 남겨 둠.

## 3. 검증

- `npx tsc -b` 0건, `npm run build` 성공.
- 개발 서버 800×600:
  - 시작 화면: 카드 2장(A4 기본·빈 격자)·부제 없음·"말판 파일 열기" 버튼·하단 출처 표시 확인. 콘솔 오류 0건.
  - 상단바: [열기][저장▾] │ [미리보기][정답][PDF 저장]. 저장 안 된 상태에서 열기 → "저장하지 않고 열기" 확인 모달.
  - 격자선: 있는 토막 위 = 빨강 미리보기, 누르면 지워지고 같은 자리 = 파랑. 종이 가장자리 반 칸 = 진입로 미리보기.
  - 출발 마커 선택 → 모서리 핸들 4개, 끌어서 scale 1.95 저장(초안에서 확인).
  - PDF 저장 화면: 용지 드롭다운(A4 기본), 방향 "가로 · 추천", 2장 결과, 체크 4개 모두 해제 상태.
  - 정답: 격자 탭 "기능 구현중" 카드, 코드 복사 비활성.
- PDF(10×4, A4 가로 2장)를 PyMuPDF로 렌더해 확인: 1-1은 맵 오른쪽 끝이 용지 끝 8mm(왼쪽은 바깥 여백), 1-2는 맵 왼쪽이 8mm이고 그 자리에 "자르기" 점선 한 줄. 겹치기 5mm는 1-2 왼쪽에 옅은 띠 + 띠 가운데 점선.
- 햄스터S 윗면 아이콘·1.5배 햄스터 마커가 PDF에 정상 출력.
- 실제 프린터 인쇄·가위질 실기 검증은 사용자 확인 필요.
