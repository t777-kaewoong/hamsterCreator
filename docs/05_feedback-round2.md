# 05. 사용자 후기 2차 — 도구 결함·인쇄 옵션 (2026-09-29)

> 순서: 원인 분석 → 해결 방향 → 명세 → 검증. docs/04 다음 회차입니다.

## 1. 후기와 원인

| # | 후기 | 원인(코드 확인) |
|---|---|---|
| 1 | 타일 집기로 누르면 선택은 되는데 타일 배치 팔레트에서 안 보임 | `setStampTile`이 도구만 B로 바꾸고 팔레트 "종류"는 그대로 둠. 숲 타일을 집어도 팔레트는 던전을 보여 줘 선택 표시가 화면에 없음 |
| 2 | 타일 위에 선이 그어지는 타일이 많음 | 바닥 11종(돌바닥·얼음 바닥·캔디 줄무늬 등)이 `aboveLine: false`, 교사가 올린 이미지도 선 아래. 공식 `board_game.pdf`를 렌더해 보면 사암 바닥·캔디 줄무늬도 **선을 덮음**. 오려서 올려놓는 타일이라 실물에서도 항상 선을 가림 |
| 3 | 지우개가 어려움. + 를 ㅏ로 못 바꿈, 획 지우기도 어려움 | 지우개는 칸 타일만 지움. 선은 Alt를 누른 채 노드→노드로 끌어야 했고, 곡선·글자·자유 배치 그림은 못 지움. 무엇이 지워질지 표시도 없음 |
| 4 | 글자 기능 동작 안 함 | 캔버스를 누르면 pointerdown에서 입력칸을 띄우고 포커스를 주는데, 뒤이은 **mousedown 기본 동작**이 포커스를 캔버스 쪽으로 빼앗음 → 입력칸 blur → 빈 글자로 확정 → 라벨 즉시 삭제 |
| 5 | 곡선 펜 더블클릭해도 완료 안 됨 | 더블클릭을 `e.detail >= 2`로 판정했는데 크롬 pointerdown의 detail은 항상 0. 선택 도구의 "경로 더블클릭으로 정점 추가"도 같은 이유로 동작 안 했음 |
| 6 | 인쇄 전에 새 말판·조립 안내도를 넣을지 체크박스로 고르고 싶음 | 조립 안내도(제목 "새 말판 · 조립 안내도")는 여러 장이면 무조건 붙음. 한 장이면 인쇄 버튼이 바로 PDF를 내려받아 고를 기회가 없음 |
| 7 | 인쇄 여백이 너무 넓은 것 아닌가? | **의도된 값.** 칸 50mm를 지키면 A4 가로(297mm)에 5칸(250mm)까지만 들어가 좌우 23.5mm, 위아래 5mm가 남음. 공식 `playbot_A4.pdf`·`custom_board_game_A4.pdf`와 같은 배치(렌더 비교 확인). 늘려 채우면 칸이 50mm가 아니게 되어 로봇 이동 거리·정품 타일과 어긋남 |

## 2. 해결 방향과 명세

### 2.1 타일 집기 (1)
- `setStampTile(id)`가 팔레트 종류도 맞춤: 내장 타일 → 그 테마, 인쇄용 아이콘 → `icon`, 올린 이미지 → `myImages`.
- 타일 집기는 검색어도 비움(검색 결과에 없을 수 있으므로). 팔레트 클릭은 검색어 유지.
- 선택된 팔레트 타일은 `scrollIntoView({ block: 'nearest' })`로 보이게 함.

### 2.2 타일은 모두 선 위 (2)
- manifest 35종 `aboveLine: true`. 판단은 `isTileAboveLine(art)` 하나(캔버스·PDF·썸네일 공용). 카탈로그 밖(아이콘·올린 이미지)도 true.
- 선택 판정도 "칸 타일 → 곡선" 순서로 바꿈(화면에서 앞에 보이는 것 먼저).

### 2.3 지우개 (3) — `features/canvas/eraseTarget.ts`
- 규칙: **보이는 것 중 맨 위를 지운다.** 글자 → 자유 배치 그림 → 칸 타일 → 격자선 한 토막 → 곡선 → 경계 진입로.
- 격자선 한 토막 = 이웃 노드 사이 선 하나. 가장 가까운 노드에서 가로/세로 중 더 벗어난 쪽 토막을 고름. 선 굵기 절반 + 4mm 안이면 맞힌 것으로 봄. + 의 왼쪽 팔을 누르면 ㅏ.
- 끌기: 5mm 간격으로 훑고 **처음 맞힌 종류만** 지움(선을 문지르다 타일까지 지우지 않게). 빈 곳에서 시작하면 처음 맞힌 종류로 고정. Alt는 "선만".
- 미리보기: 커서 아래 지울 대상을 `--c-danger`로 덮음. 칸·글자·그림은 채움 28% + 2px 테두리, 선·진입로·곡선은 실제 굵기 + 2mm, 70%.
- 끌기 한 번 = 실행취소 한 단계(기존 제스처 규칙).

### 2.4 글자 (4)
- 캔버스 본체의 `mousedown` 기본 동작을 막아 포커스를 옮기지 않음. 대신 pointerdown에서 입력 중이던 다른 입력칸(인스펙터 등)을 직접 blur해 확정.
- 라벨 입력칸 자체는 도구 입력에서 제외(`data-canvas-ui`) — 안을 눌러 커서를 옮겨도 새 라벨이 생기지 않음.

### 2.5 더블클릭 (5)
- `ToolController.isDoubleClick`: 이전 왼쪽 누름과 450ms·8px 이내면 더블클릭. 세 번째 누름이 다시 잡히지 않게 기록을 비움. 곡선 펜 완료와 선택 도구 정점 추가에 사용.

### 2.6 인쇄 옵션 (6)
- 인쇄 버튼은 항상 출력 계획기를 엶(한 장이어도). 편집 중인 용지가 선택된 채 열리므로 한 번 더 누르면 됨.
- 계획기 "PDF에 넣을 것" 체크박스 4개(2열): 조립 안내도 / 재단선·맞춤 표시 / 50mm 확인 자 / 안내 문구·시트 번호. 앞의 둘은 한 장이면 비활성.
- `PrintConfig`에 선택 필드 `assemblyGuide?`, `notice?` 추가(없으면 true — 예전 파일 호환). 값은 PDF를 만들 때 문서에 저장.
- 안내 문구를 끄면 가장자리 문구와 시트 안 번호·이웃 시트 안내도 함께 뺌.

### 2.7 여백 (7)
- 동작은 바꾸지 않음. 계획기 미리보기 제목 아래에 "종이 여백 좌우 23.5mm · 위아래 5mm — 칸을 실제 50mm로 지키려고 남는 부분입니다(공식 말판과 같음)"를 표시.

## 3. 검증 (2026-09-29)

- 타입 검사 0건, `npm run build`·`build:single` 성공, 크기 변경 회귀 스크립트 26항목 통과.
- 지우개 판정(개발 서버에서 모듈 직접 호출): 노드 (2,2)의 왼/오/위/아래 팔 → 각각 h(1,2)/h(2,2)/v(2,1)/v(2,2), 타일 위 → 타일, 글자 위 → 글자, 원만 있는 곳 → 곡선, 격자 바깥 → 진입로, 빈 칸 모서리 → 없음. 왼쪽 팔 지우기 후 나머지 세 팔 유지(+ → ㅏ).
- 타일 집기: 던전 팔레트에서 숲 수풀 선택 → 종류 "숲", 수풀 선택 표시. 아이콘 → 종류 "아이콘".
- 곡선 펜: 점 두 개 후 같은 자리 두 번 누름 → 곡선 1개 생성.
- 글자: 캔버스 mousedown 기본 동작 차단 확인, 입력칸 생성·포커스 유지.
- PDF: 돌바닥 타일이 격자선을 덮음. 옵션 전부 켬 = 3쪽(2장 + 안내도), 전부 끔 = 2쪽·문구 없음.
- 한계: 앱 창이 가려져 캔버스가 기본 300×150으로 잡혀 실제 마우스 좌표 조작은 못 함. 지우개 빨간 미리보기와 실제 마우스 글자 입력은 선생님 화면에서 한 번 확인 필요.
