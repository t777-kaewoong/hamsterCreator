# 11. 사용자 후기 8차 — 출발·도착 선 위/아래 (2026-10-27)

> 순서: 원인 분석 → 해결 방향·명세 → 검증. docs/10 다음 회차입니다.

## 1. 후기와 원인

| 후기 | 원인(코드 확인) |
|---|---|
| 출발·도착도 선 위/아래를 설정하고 싶음 | 타일·그림은 docs/09에서 선 위/아래를 고를 수 있게 됐지만, 출발·도착 마커는 늘 맨 위 레이어(격자선 위)에 흰 바탕을 깔고 그려짐 |

## 2. 해결 방향·명세

- `StartMarker.under?`, `GoalMarker.under?`(없으면 선 위 = 지금과 같음).
- **몸통만** 선 아래로 내려가고 **이름표(출발·도착 이름)는 늘 맨 위**에 그림. 검은 선에 이름이 가려지지 않게 하려는 것.
  - 화면: 아트 레이어(격자선 아래)에서 선 아래 마커 몸통을 그리고, 맨 위 레이어에서 나머지 몸통과 모든 이름표(`drawMarkersLayer(…, aboveGrid)`).
  - PDF: 같은 규칙(`drawMarkers(context, aboveGrid)`). 썸네일도 아트 레이어를 거치므로 같음.
- 팔레트(출발지·도착지 모드, "모양" 아래): **"선 아래에 깔기"** 체크. 체크 상태는 지금 놓인 출발(또는 모든 도착)의 실제 상태를 보여 주고, 바꾸면 그 마커들에 바로 적용 + 이후 놓는 것도 따름(모양 고르기와 같은 규칙).
- 인스펙터(출발·도착 선택): **"선과 순서: 선 위 / 선 아래"**로 하나씩 바꾸기.

## 3. 검증 (2026-10-27)

- `npx tsc -b` 0건, `npm run build`·`build:single` 성공, 크기 변경 회귀 31항목 통과.
- 개발 서버(A4 기본, 전체 격자): 출발(기본 모양) 팔레트 체크 → `under: true`, 격자선 +자가 원 위로 지나가고 "출발" 이름표는 위에 보임. 도착(햄스터, 아래 보기) 모드로 바꾸면 체크가 꺼진 상태로 보이고(실제 상태), 체크 → `under: true`, 사진 위로 격자선이 지나가고 "도착" 이름표는 위. 인스펙터 "선과 순서" 줄 표시.
